## 1. circle.py

***Общее описание решения***\
Программа имеет 2 функции: area и perimeter. 
На вход программа ничего не принимает.

Код программы: 
```py
import math


def area(r):

    ''' 
    Получает на вход радиус окружности r, возвращает площадь окружности
    Пример вызова: 
        area(1) -> 3.141592653589793  
    '''

    return math.pi * r * r


def perimeter(r):

    ''' 
    Получает на вход радиус окружности r, возвращает периметр окружности 
    Пример вызова: 
        perimeter(3) -> 18.84955592153876
    '''

    return 2 * math.pi * r
```

***Описание каждой функции с примерами вызовов***
1) **area($r$)**: 
   - *Описание:*  получает на вход радиус окружности $r$ и возвращает площадь окружности 
   - *Примеры вызова:*
     - area($1$) = $3.141592653589793$
     - area($3$) = $28.274333882308138$

2) **perimeter($r$)**:
   - *Описание:* получает на вход радиус окружности $r$ и возвращает периметр окружности 
   - *Примеры вызова:*
     - perimeter($1$) = $6.283185307179586$
     - perimeter($13$) = $81.68140899333463$

## 3. rectangle.py

***Общее описание решения***\
Программа имеет 2 функции: area и perimeter. 
На вход программа ничего не принимает.

Код программы:
```py
def area(a, b):

    ''' 
    Получает на вход длины стороны a и b, возвращает площадь прямоугольника 
    Пример вызова: 
        area(1, 2) -> 2
    '''

    return a * b


def perimeter(a, b):

    ''' 
    Получает на вход длины стороны a и b, возвращает периметр прямоугольника
    Пример вызова:
        perimeter(14, 2) -> 32 
    '''

    return 2 * (a + b)
```

***Описание каждой функции с примерами вызовов***
1) **area($a$, $b$)**: 
   - *Описание:*  получает на вход длины сторон прямоугольника $a$ и $b$ и возвращает площадь прямоугольника 
   - *Примеры вызова:*
     - area($1$, $2$) = $2$
     - area($5$, $4$) = $20$

2) **perimeter($a$, $b$)**:
   - *Описание:* получает на вход длины сторон прямоугольника $a$ и $b$ и возвращает периметр прямоугольника 
   - *Примеры вызова:*
     - perimeter($14$, $2$) = $32$
     - perimeter($3$, $7$) = $20$


## 4. triangle.py

***Общее описание решения***\
Программа имеет 2 функции: area и perimeter. 
На вход программа ничего не принимает.

Код программы:
```py
def area(a, h):

    ''' 
    Получает на вход длину стороны a, высоту треугольника h и возвращает площадь треугольника S 
    Пример вызова: 
        area(4, 12) -> 24 
    '''

    return a * h / 2


def perimeter(a, b, c): 

    ''' 
    Получает на вход длины 3х сторон a, b, c и возвращает периметр треугольника
    Пример вызова:
        perimeter(3, 4, 5) -> 12
    ''' 

    return (a + b + c)
```

***Описание каждой функции с примерами вызовов***
1) **area($a$, $h$)**: 
   - *Описание:*  получает на вход длину стороны треугольника $a$, высоту $h$ и возвращает площадь треугольника 
   - *Примеры вызова:*
     - area($4$, $12$) = $24$
     - area($6$, $5$) = $15$

2) **perimeter($a$, $b$, $c$)**:
   - *Описание:* получает на вход длины трёх сторон треугольника $a$, $b$, $c$ и возвращает периметр треугольника 
   - *Примеры вызова:*
     - perimeter($3$, $4$, $5$) = $12$
     - perimeter($1$, $2$, $3$) = $6$
